# 123 云盘客户端（WebDAV · mygo 原生 UI）

123 云盘官方 OpenAPI 需要购买「开发者权益包」，所以本项目走标准 **WebDAV** 协议。

## 目前的功能
1. 展示目录树
2. 展示文件列表
3. 同步目录树和文件列表（同步之后存在本地缓存，缓存在exe当前目录下）
4. 搜索（基于本地缓存）
5. 重复文件检测（基于本地缓存，策略是 文件名一致，暂时没有实现基于hash的判定策略）
6. 单个文件的删除功能（使用请谨慎）
7. 新建、修改--暂时没有实现


## 使用

1. 打开程序 → 点「设置…」：WebDAV 地址默认是 `https://webdav.123pan.cn/webdav`（可点「填入 123 云盘地址」恢复）。
2. 填 **用户名 / 密码**（123 云盘账号的 WebDAV 凭证，见官方文档；凭证不正确时接口会返回 401）→「测试连接」→ 保存。
3. 首次启动会自动同步根目录第一层；之后在树上选中任意目录，点「同步选中目录(和子目录)」或「同步选中目录(单层)」即可。

### 操作提示

| 操作 | 效果 |
| --- | --- |
| 点击目录前的展开箭头 | 展开子文件夹；有缓存则离线展开，没有缓存则自动同步这一层（1 次 PROPFIND） |
| 在目录树中点选文件夹 | 右侧立即显示该目录的文件夹和文件；未缓存时会自动同步这一层 |
| 点击文件列表上方的路径（面包屑） | 跳转到路径中的任意一级目录 |
| 双击文件列表中的文件夹 | 进入该目录（目录树同步选中并展开） |
| 点击文件列表行尾的垃圾桶 | 删除该文件/文件夹（先弹出确认框，确认后不可恢复） |
| 选中文件夹 + 「同步选中目录(和子目录)」 | 递归同步该文件夹及其整棵子树（未选中时同步根目录） |
| 选中文件夹 + 「同步选中目录(单层)」 | 只刷新该文件夹这一层（1 次 PROPFIND），不进入子目录 |
| 搜索框 | 输入即搜（仅本地缓存，忽略大小写，空格分隔多个关键字） |
| 「重复文件检测」 | 在本地缓存中找同名文件（不含文件夹），左侧同名文件名、右侧文件详情；可「重新检测」 |
| 双击检测结果中的文件 | 回到目录树并定位该文件（只用缓存，不联网） |
| 双击搜索结果 | 文件夹：在目录树中逐级展开并选中；文件：选中其父目录并在右侧列表中高亮该文件（只用缓存，不联网） |
| 「停止」 | 取消当前同步并清空排队任务 |
| 底部日志面板 | 每个目录的同步结果、缓存命中、限速等待都在这里；默认约占窗口 1/4，可拖动分隔条调整，双击分隔条恢复默认比例 |

## 数据存放

所有数据都在**程序当前工作目录**（通常就是 exe 所在目录），整个目录可以直接拷贝带走：

| 文件 | 说明 |
| --- | --- |
| `config.json` | WebDAV 地址 / 用户名 / 密码 / 是否忽略证书 / QPS |
| `tree.db` | SQLite 目录树缓存（DELETE 日志模式，**不会产生** `-wal`/`-shm` 常驻文件） |

`config.json` 示例：

```json
{
  "webdavUrl": "https://webdav.123pan.cn/webdav",
  "username": "user",
  "password": "pass",
  "insecureTls": false,
  "qps": 5
}
```

> 想删掉缓存重新同步，直接关闭程序后删 `tree.db` 即可；表结构见 [tech.md](tech.md)。

## 技术简要概述
用 **Go + [mygo](https://github.com/egoist/mygo)** 写的 Windows 桌面客户端：GPU 直接绘制原生界面（没有 HTML / JavaScript / webview），用目录树浏览 WebDAV 上的文件，目录缓存到本地 SQLite，按需同步，支持只查本地缓存的模糊搜索和同名文件检测。

123 云盘官方 OpenAPI 需要购买「开发者权益包」，所以本项目走标准 **WebDAV** 协议。

**123 云盘官方 WebDAV 地址：`https://webdav.123pan.cn/webdav`**（Basic Auth），程序默认就填这个地址；也可以填任意其它 WebDAV 服务（NAS、Alist、自建等）。

## 能做什么

| 功能 | 说明 |
| --- | --- |
| 目录树 + 文件列表 | 左侧只显示文件夹，右侧显示当前目录的文件夹和文件（名称 / 大小 / 创建时间 / 修改时间 / ETag）；两栏可拖动调整宽度 |
| 面包屑导航 | 文件列表上方的 `我的云盘 › 相册 › 2023` 点击任意一级即可跳转；双击列表中的文件夹也能进入 |
| 离线浏览 | 启动即从本地 SQLite 缓存渲染，断网也能浏览已同步的内容 |
| 按需同步 | 「同步选中目录(和子目录)」递归同步整棵子树，「同步选中目录(单层)」只刷新当前层；展开未缓存的目录自动同步一层 |
| QPS 限速 | 所有请求串行经过同一个限速器（默认 5 QPS，可调 0.2~50），429 / 5xx 自动退避重试 |
| 停止 | 随时取消当前同步并清空排队任务 |
| 本地搜索 | 文件名模糊搜索（忽略大小写，空格分隔多关键字），**只查本地缓存，不联网** |
| 重复文件检测 | 在缓存中找同名文件（不算文件夹），双击结果可定位到目录树，同样不联网 |
| 删除 | 文件列表行尾的垃圾桶按钮，二次确认后调用 WebDAV `DELETE`，**不可恢复** |
| 日志面板 | 底部实时显示每个目录的同步结果、缓存命中、限速等待 |
| 窗口状态记忆 | 窗口大小 / 位置 / 最大化状态自动记住 |

## 环境要求

- Windows 10 / 11（amd64）
- **Go 1.27.3+**（mygo v0.9.2 的要求；`go.mod` 里写了 `toolchain go1.27.4`，本机 Go 较旧时会自动下载对应工具链）
- 无需 CGO；原生 UI 不需要 Bun / Node

## 构建

```bash
# 开发运行（会弹出一个原生窗口）
go run .

# 编译（-H windowsgui 表示不带控制台窗口；rsrc.syso 会自动链接进 exe）
go build -trimpath -ldflags "-s -w -H windowsgui" -o 123pan-client.exe .
```

或者直接运行 `build.bat`（gofmt + go build；`rsrc.syso` 不存在时会先打包图标）。

> 图标源图在 `res/keji.svg`，重新生成图标、PE 资源等细节见 [tech.md](tech.md) 的「应用图标」一节。



## 注意事项

- 支持浏览、同步与**删除**；不含上传 / 下载 / 重命名。删除直接调用 WebDAV `DELETE`，**不可恢复**（123 云盘可能会把文件放进回收站，视服务端行为而定）。
- 搜索与查重范围仅限**已同步到本地缓存**的条目（未同步的目录不在结果里），这也是「不与服务器交互」的代价。
- 大目录树递归同步耗时受 QPS 限制（默认 5 QPS），建议先同步一层再逐级展开。
- 123 云盘官方 WebDAV 可能需要对应会员 / 权限，凭证以官方 WebDAV 文档为准；连接失败时先检查 401 提示里的账号密码。

## 安全提示

本项目是**个人本地使用**的工具：`config.json` 以明文保存 WebDAV 用户名 / 密码，请勿把该文件分享给他人（该文件已在 `.gitignore` 中）。
